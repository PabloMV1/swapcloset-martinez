# SwapCloset - Backend

Backend de una app de intercambio y préstamo de ropa (2º DAM, Acceso a Datos).

## Arranque
```bash
docker compose up -d
./mvnw spring-boot:run
```
Swagger UI: http://localhost:8080/swagger-ui.html

## Variables de entorno
Ver `.env.example`.
